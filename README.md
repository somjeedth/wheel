# วงล้อแจกของรางวัล

หน้าเว็บวงล้อสุ่มของรางวัล เป็น HTML ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

## ความสามารถ
- สุ่มของรางวัลจากวงล้อ ของที่สุ่มได้แล้วจะถูกตัดออกจากวงล้อ
- ปุ่ม **สลับตำแหน่ง** จัดช่องใหม่ให้ของชนิดเดียวกันไม่อยู่ติดกัน
- ปุ่ม **คืนของ** ในผลการสุ่ม ใช้ยกเลิกรายการที่กดผิด ของจะกลับเข้าวงล้อ
- **เพิ่ม/ลดของรางวัล** ได้ในเมนู “ของที่เหลือ” (ปุ่ม + / − และช่องเพิ่มของใหม่)
- พลุ คอนเฟตตี ไฟวิ่งรอบวงล้อ และเสียงเอฟเฟกต์ (สร้างด้วย Web Audio) พร้อมปุ่มปิดเสียงและแถบปรับความดัง
- รองรับมือถือ และโหมดมืด/สว่าง

## ของรางวัลเริ่มต้น
หมอนอิง ×2, กระเป๋าเดินทาง, หมวก, กระเป๋าสะพาย, แก้วชมพู ×3, แก้วฟ้า ×2, แก้วส้ม ×2 (รวม 12 ชิ้น)

## ใช้ร่วมกันหลายคน (Supabase)
ของรางวัลและผลการสุ่มเก็บในฐานข้อมูล Supabase (ตาราง `wheel_*`) ทุกคนที่เปิดหน้านี้เห็นวงล้อเดียวกันแบบเรียลไทม์
ถ้าคนหนึ่งสุ่มได้ ของที่เหลือของทุกคนจะลดลงทันที

- การสุ่มทำในฐานข้อมูล (`wheel_claim`) จึงไม่มีทางที่สองคนกดพร้อมกันแล้วได้ของชิ้นเดียวกัน
- ผู้เล่นใส่ชื่อก่อนหมุนครั้งแรก (จำไว้ในเบราว์เซอร์) และ “คืนของ” ได้เฉพาะของที่ตัวเองได้
- **ผู้ดูแล** ใส่รหัสผู้ดูแลในเมนู “ของที่เหลือ” เพื่อ เพิ่ม/ลดของรางวัล, คืนของของทุกคน และรีเซ็ตวงล้อ
- โครงสร้างฐานข้อมูลอยู่ใน `supabase/schema.sql` · ค่า URL และ publishable key อยู่ใน `index.html` (key นี้เปิดเผยได้ ข้อมูลถูกป้องกันด้วย RLS และฟังก์ชันในฐานข้อมูล)
- เปลี่ยนรหัสผู้ดูแลได้ใน Supabase SQL Editor:
  ```sql
  update public.wheel_settings set admin_pin_hash = extensions.crypt('รหัสใหม่', extensions.gen_salt('bf')) where id = 1;
  ```

ถ้าโหลดฐานข้อมูลไม่ได้ หน้าเว็บจะเปลี่ยนเป็นโหมดเครื่องเดียวอัตโนมัติ (เก็บใน `localStorage`)

## วิธีเปิด
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือรันเว็บเซิร์ฟเวอร์แบบง่าย

```bash
python3 -m http.server 8000
```

หรือ deploy เป็นเว็บ static บน GitHub Pages / Vercel / Netlify ได้ทันที (Settings → Pages → branch `main`)
