# วงล้อแจกของรางวัล

หน้าเว็บวงล้อสุ่มของรางวัล เป็น HTML ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

## ความสามารถ
- สุ่มของรางวัลจากวงล้อ ของที่สุ่มได้แล้วจะถูกตัดออกจากวงล้อ
- ปุ่ม **สลับตำแหน่ง** จัดช่องใหม่ให้ของชนิดเดียวกันไม่อยู่ติดกัน
- ปุ่ม **คืนของ** ในผลการสุ่ม ใช้ยกเลิกรายการที่กดผิด ของจะกลับเข้าวงล้อ
- **เพิ่ม/ลดของรางวัล** ได้ในเมนู “ของที่เหลือ” (ปุ่ม + / − และช่องเพิ่มของใหม่)
- พลุ คอนเฟตตี ไฟวิ่งรอบวงล้อ และเสียงเอฟเฟกต์ (สร้างด้วย Web Audio) พร้อมปุ่มปิดเสียงและแถบปรับความดัง
- รองรับมือถือ และโหมดมืด/สว่าง

## ของรางวัลเริ่มต้น
หมอนอิง ×2, กระเป๋าเดินทาง, หมวก, กระเป๋าสะพาย, แก้วชมพู ×3, แก้วฟ้า ×2, แก้วส้ม ×2 (รวม 12 ชิ้น)

## วิธีเปิด
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือรันเว็บเซิร์ฟเวอร์แบบง่าย

```bash
python3 -m http.server 8000
```

หรือ deploy เป็นเว็บ static บน GitHub Pages / Vercel / Netlify ได้ทันที

## โหมดการทำงาน
- **เปิดจากไฟล์นี้ / GitHub Pages / Vercel:** เป็น *โหมดเครื่องเดียว* — ของรางวัลและผลการสุ่มเก็บใน `localStorage` ของเบราว์เซอร์นั้น ไม่แชร์กับคนอื่น
- **เปิดผ่าน Claude Artifact:** ทุกคนใช้วงล้อเดียวกัน ของที่มีคนสุ่มได้จะหายจากวงล้อของทุกคนแบบเรียลไทม์ (ใช้ฐานข้อมูลของ Artifact)

ถ้าต้องการให้เวอร์ชันบนเว็บของตัวเองใช้ร่วมกันหลายคน ต้องต่อฐานข้อมูลเพิ่ม (เช่น Supabase / Firebase)
